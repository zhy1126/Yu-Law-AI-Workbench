虞律团队 AI 工作流使用手册

这份手册说明团队怎样在 WorkBuddy 中接收任务、整理材料、选择 Skill、生成成果并完成律师复核。安装只需要完成一次，后面的工作流是日常使用重点。

适用对象：虞律团队成员使用方式：按任务节点查阅更新：2026 年 8 月
工作原则先推荐、律师确认后执行。AI 生成成果后，任务进入“待律师复核”。

00

开始使用前的检查

  • □ WorkBuddy 可以正常打开并登录。
  • □ 能进入“虞律团队 AI 工作流试验”项目。
  • □ 能看到团队计划栏、资源库以及项目材料。
  • □ 能找到“法律 AI 工作流总入口”。
  • □ 能用本页连接测试 Prompt 得到正确回复。
  • □ 能用虚拟材料把任务推进到“待律师复核”，且没有自动批准、归档或发送。
第一次先用虚拟材料

演练通过后，真实客户材料再按照项目权限进入对应工作区。不要把客户文件放进公开链接或无关项目。

01

三个工作入口分别做什么

Skill 库

查找团队现有能力、适用任务、输入输出和安装来源。它不直接保存客户文件。

团队使用指南

说明 WorkBuddy 安装、任务流程、可复制 Prompt、文件规范与律师复核要求。

诉讼案例管理

管理案件、期限、待办、文书和周报。数据统一保存在 PythonAnywhere 私有后台。

WorkBuddy

团队实际处理材料和调用 Skill 的地方。计划栏负责进度，任务工作区保存材料和成果。

WorkBuddy 发起任务→总入口推荐 Skill→律师确认→Skill 执行→律师复核

02

日常工作流怎么运转

  1. 1

    事项进入计划栏

    周会行动项由周协同整理；日常新增事项由发起人建立。至少写清名称、负责人、期限和所属项目。

  2. 2

    判断是否建立专业子任务

    涉及文书起草、合同审阅、尽调、并购、IPO 或专题研究时，建立独立任务进入法律 AI 工作流。

  3. 3

    整理和确认材料

    逐项确认文件名、版本、委托方立场、适用法域和缺失材料。

  4. 4

    总入口只推荐 Skill

    先推荐 1–3 个 Skill，说明理由、输入、输出、缺口和风险，不立即执行。

  5. 5

    律师确认后执行

    律师确认 Skill、材料范围、工作范围和输出形式后，任务进入“生成中”。

  6. 6

    成果回到任务

    Word、Excel、问题清单或分析意见保存在任务工作区，写明文件名、版本和待确认项。

  7. 7

    律师复核并更新计划

    AI 只推进到“待律师复核”。律师复核后手动批准、归档，并更新计划栏。

03

安装 WorkBuddy

  1. 下载安装打开 WorkBuddy 官方下载页，选择 Mac 或 Windows 版本。
  2. 完成登录打开 WorkBuddy，确认服务条款后，使用微信扫码登录。
  3. 接受项目邀请使用同一账号接受管理员邀请，加入“虞律团队 AI 工作流试验”。
  4. 检查团队内容确认能看到计划栏、资源库、项目材料和“法律 AI 工作流总入口”。
  5. 检查更新在头像或个人中心菜单运行“检查更新”。

04

首次设置与第一次演练

  1. 进入正确项目项目标题应为“虞律团队 AI 工作流试验”。看不到时先核对登录账号。
  2. 找到总入口在专家区域搜索“法律 AI 工作流总入口”，选择说明中含“先推荐、律师确认后执行”的版本。
  3. 建立虚拟演练任务名称建议写“YULAW-DEMO｜任务类型｜姓名｜日期”，与真实案件分开。
  4. 先用 Ask 模式连接测试、材料清点和 Skill 推荐先用“问一问”；复杂任务可先用“想一想”查看计划。
  5. 确认后再执行律师确认 Skill、材料、立场和输出后，再进入“做一做”。

05

可直接复制的 Prompt

复制后把【】中的内容改成当前任务信息。

Prompt 01｜连接测试

确认当前专家和基本工作原则。

这是连接测试。请不要读取文件、不要调用 Skill、不要连接外部服务，也不要生成正式成果。

请只回复以下三项：
1. 你当前使用的专家名称；
2. 你是否理解“先推荐、律师确认后执行”；
3. 你能否在未获确认前停止执行。

如果当前不是“法律 AI 工作流总入口”，请直接提醒我切换专家。
Prompt 02｜材料清点

只确认文件和缺口，不开始工作。

这是【项目/任务名称】的材料清点，不是正式审阅或起草。

委托方立场：【填写】
任务目标：【填写】
截止时间：【填写】
已提供材料：【逐项填写文件名】

请只输出：
1. 已收到的文件及版本；
2. 可能重复、过期或无法识别的文件；
3. 开始工作前仍缺少的材料；
4. 必须由律师确认的事实。

不要调用 Skill，不要改文件，不要开始起草或审阅。
Prompt 03｜Skill 推荐

推荐后等待律师选择。

这是【项目/任务名称】。先不要执行。

任务类型：【报价函/标书/法律服务建议书/合同起草/合同审阅/尽调/并购结构/IPO 等】
委托方立场：【填写】
适用法域：【填写】
目标成果：【填写】
材料范围：【填写文件名或文件夹】
特别关注：【填写】

请只推荐 1–3 个最适合的 Skill，并逐一说明：
1. 匹配理由；2. 所需输入；3. 交付成果；4. 当前缺口；5. 风险和律师确认点。

请给出首选方案，但等我确认后再执行。
Prompt 04｜确认执行

律师确认范围后使用。

确认采用【Skill 名称】执行本任务。

委托方立场：【填写】
确认材料范围：【填写】
任务范围：【填写】
不在范围内的事项：【填写；没有则写“无”】
输出格式：【填写】
截止时间：【填写】

执行要求：只使用确认材料；不确定事实必须标记；发生冲突先停止；所有成果标记“待经办律师复核”；不得自动批准、归档、上传、分享或对外发送。
Prompt 05｜暂停并确认

出现事实缺口或冲突时使用。

请暂停当前生成，不要继续修改文件。

请把尚未解决的问题整理为确认清单，每项包括：编号、待确认事实或选择、影响、可选方案、建议确认人。

等我逐项回复后，再总结确认内容并询问是否恢复执行。
Prompt 06｜交付前自检

辅助律师检查，不替代批准。

请对当前成果做一次“交付前自检”，但不要替律师批准。

逐项检查并引用位置：委托方立场；主体、金额、比例、日期和版本；批注、占位符和待确认项；法律依据；用户要求的输出；文件名和格式；不应披露的信息。

最后只输出“复核清单 + 发现的问题 + 建议处理方式”，并保持状态为“待律师复核”。
Prompt 07｜状态汇报

只查看进度，不继续执行。

请只汇报当前任务状态，不要继续执行。

- 当前阶段：
- 已完成：
- 正在处理：
- 缺少材料：
- 待律师确认：
- 已生成成果及保存位置：
- 下一步建议：

未经律师复核，不得写“已完成”或“可直接发送”。
Prompt 08｜立即停止

发现越权或方向错误时使用。

立即停止当前任务，不再调用任何 Skill、脚本、连接器或外部服务，也不要修改、上传、分享、批准或归档任何文件。

请只说明：停止前最后完成的步骤、已经发生的文件变更、当前成果位置、需要人工检查或恢复的事项。

06

材料和文件命名

  • 项目材料：放在该任务或案件的专用工作区，不放在 Skill 库网页。
  • 团队资源：批准的通用模板、案例、律师履历和使用规范放团队资源库。
  • 文件名：建议使用“项目简称_文件类型_版本_日期”，例如 虚拟A公司_投资协议_v03_20260817.docx。
  • 版本：材料清点和成果交付都写明使用版本；不要用“最新版”“最终版2”代替明确版本。

07

六阶段工作流

  1. 1待收件
  2. 2材料已确认
  3. 3生成中
  4. 4待律师复核
  5. 5已批准
  6. 6已归档
人工确认节点

AI 自动执行只到“待律师复核”。“已批准”“已归档”以及正式对外发送，均由具名经办律师手动确认。

08

律师复核清单

事实

  • 主体、姓名、金额、比例、日期
  • 文件版本和交易阶段
  • 委托方立场

法律

  • 适用法域和法律依据
  • 引用是否真实、现行、可核验
  • 事实与法律结论是否区分

完整性

  • 要求的输出是否齐全
  • 是否遗漏条款或附件
  • 待确认事项是否保留

文件

  • 批注、占位符和修订痕迹
  • 格式、页码、目录和文件名
  • 交付版本与复核版本一致

保密

  • 是否含其他客户信息
  • 是否误用了公开位置
  • 发送范围是否获批准

记录

  • 批准人和批准时间
  • 最终版本号
  • 归档位置和后续待办

09

常见问题

看不到团队项目
核对接受邀请的账号与 WorkBuddy 登录账号是否一致；不要自行新建同名项目。
专家或 Skill 不可见
刷新项目，在“我的专家”或“已安装 Skill”核对完整名称；仍不存在时联系管理员。
文件无法读取
检查文件能否在本机打开、是否加密、是否为临时文件，并确认它位于当前授权工作区。
它跳过推荐直接执行
立即使用 Prompt 08 停止，重新选择“法律 AI 工作流总入口”，再用 Prompt 03。
结果看起来不对
不要批准。停在“待律师复核”，补充立场、模板、版本和输出要求后再决定是否重做。
